# desarmalo-social

Espacio de trabajo del departamento de marketing de **desarmalo.cl**.

Contacto/cuentas: desarmalochile@gmail.com

## Estructura

| Carpeta | Contenido |
|---|---|
| `brand/` | Identidad: voz y tono, paleta, logo, reglas de uso |
| `strategy/` | Objetivos, audiencias, pilares de contenido, competencia |
| `calendar/` | Calendario editorial mensual |
| `content/` | Piezas listas o en borrador (posts, carruseles, reels, stories) |
| `assets/` | Imágenes, videos y fuentes |
| `agents/` | Roles del equipo (cada archivo define un puesto) |
| `reports/` | Métricas y reportes periódicos |
| `ops/` | Cuentas, herramientas, flujo de aprobación |

## Flujo

1. Estrategia (`strategy/`) → 2. Calendario (`calendar/`) → 3. Piezas (`content/`) → 4. Aprobación → 5. Publicación → 6. Reporte (`reports/`)

Estado de cada pieza: `idea` → `borrador` → `revision` → `aprobado` → `programado` → `publicado`.
